IR JUMPKIT BUILDER v2.1
=======================
This folder contains ONE file you need: Build-IRJumpkit.ps1

EVERYTHING is embedded inside it -- no other files required.

ADMINISTRATOR NOTE:
-------------------
  Administrator rights are OPTIONAL.
  - Standard user  -> full kit minus Wireshark (everything else works fine)
  - Administrator  -> full kit including Wireshark

  The builder will ask you once at startup whether to allow installers to run.
  It clearly shows your current elevation level and what each choice gives you.
  No other .exe or .msi files run during the build -- only 7-Zip and Wireshark
  installers, and only if you consent. You are welcome to review the code.

USAGE:
------
1. Open PowerShell (as Administrator if you want Wireshark)
2. Navigate to where you extracted this file:
   cd C:\Users\User\Downloads\ir-jumpkit

3. Set execution policy for this session:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

4. Run the builder pointing at your USB drive:
   .\Build-IRJumpkit.ps1 -TargetPath "E:\"

   Or to a folder on any drive:
   .\Build-IRJumpkit.ps1 -TargetPath "D:\IR-Jumpkit"

OPTIONS:
--------
  -Force              Re-download everything even if already present
  -Offline            Skip all downloads, only create structure + write scripts
  -SkipTools "X","Y"  Skip specific tools by name

EXAMPLES:
---------
  # Full build to USB drive E:
  .\Build-IRJumpkit.ps1 -TargetPath "E:\"

  # Re-run after partial failure (re-downloads only what's missing)
  .\Build-IRJumpkit.ps1 -TargetPath "E:\"

  # Force re-download everything
  .\Build-IRJumpkit.ps1 -TargetPath "E:\" -Force

  # Skip tools you already have
  .\Build-IRJumpkit.ps1 -TargetPath "E:\" -SkipTools "Wireshark","Hayabusa"

WHAT IT BUILDS:
---------------
  01_Triage\          winpmem (full + mini), avml, LiME + IR scripts (Windows PS1 + Linux bash)
  02_Forensics\       Velociraptor, disk imaging guide (FTK Imager / dcfldd)
  03_Network\         Wireshark + tshark (requires Admin), BPF cheatsheets
  04_Malware\         ProcMon, Autoruns, YARA+rules, HitmanPro, RootkitRevealer,
                      Malwarebytes, AdwCleaner
  05_Logs\            Chainsaw
  06_Utils\           CyberChef, 7-Zip, PuTTY, HashMyFiles, jq
  07_Evidence\        Empty - write all evidence here during incidents
  08_Runbooks\        Incident runbooks
  09_Reference\       Cheatsheets, event IDs, IOC templates

AV NOTE:
--------
  YARA rules describe malicious behavior patterns.
  Your AV may flag individual .yar files. This is expected and normal.
  The tools themselves are clean. Temporarily exclude the target folder if needed:
  Add-MpPreference -ExclusionPath "E:\IR-Jumpkit"
  (Remove after build: Remove-MpPreference -ExclusionPath "E:\IR-Jumpkit")
